ABOUT THIS EDITION

Built for the field

Scope and limitations

This is an independent educational field handbook, not a NWCG, Scouting America, CDC, or NWS publication or endorsement. Its design is inspired by compact pocket field references, including the NWCG Incident Response Pocket Guide. It is not a firefighter operations guide or medical device.

Version 1.0 beta includes 99 concise outdoor and self-reliance references, 6 core Academy lessons, and 38 additional interactive practice labs. It deliberately does not provide detailed wilderness medicine, wild plant identification, avalanche rescue, or technical fireline tactics. Those subjects require specialist expertise, training, and careful source review.

Food preservation safety

Gardening and preservation information is an educational reference, not a tested canning recipe or a substitute for food-safety training. For canning, use the exact current tested instructions from USDA, NCHFP, or a university extension program. Improper methods can cause fatal botulism.

Offline & data

Core application code, visuals, field entries, and Morse tools are embedded in this one file. Optional local installation files support offline caching; no external fonts, scripts, APIs or images are required. The browser stores local notes and settings. No sign-in or network permission is required.

Offline access and installation

Checking offline availability…

On an HTTPS host, open Fieldcraft while connected, wait for the offline cache to finish, then test with Wi-Fi disconnected. Use your browser’s Install app or Add to Home Screen command if offered.

The portable HTML works without the service worker. Browser storage is device- and origin-specific; switching from a local file to GitHub Pages does not migrate data. Export JSON first. School device policies may block installation or local downloads.
